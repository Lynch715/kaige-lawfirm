# 开个律所

一款可直接在浏览器游玩的律师事务所经营模拟游戏。

从一间写字楼隔断间起步，接诉讼和非诉的案子，谈收费方案、排开庭期、攒客户，
在**创收**、**声誉**和**执业红线**三条线之间，把一家小所做成招牌——或者把执业证玩没。

> 当前进度：**第一期（地基）完成**。主循环、数据表、美术层、20 条事件、49 条核心测试全部就位。
> 施工计划见 `docs/规范-v1.md`。

## 主要玩法

- **四种开局**：大所出走（带一个老客户，前两案受竞业限制）/ 法学院明星（声望高钱少）/ 家里出钱（年抽成 + 两年之约）/ 三人草台班子（前两案只能接小案）
- 1/2/3 条随办公场地开放的并行案线
- **四个部门**：诉讼部 / 公司部 / 知产部 / 刑辩部，共 18 种案型，各有周期、收费倍率和风险倾向
- **四个阶段**：接案与方案 → 调查取证 → 论证与主攻 → 收尾交付，分别吃庭辩 / 研究 / 商务 / 尽调四种能力，涨事实 / 法理 / 博弈 / 交付四个维度
- **每周指令**：加班赶工、死磕细节、团建安抚、控成本、放手——连赶三周会出事
- **三种收费方案**（接案时定，定了不能改）：固定收费旱涝保收 / 风险代理全胜爆赚败诉白干 / 计费小时每周结算但磨客户满意度
- **两头挣钱**：管线上的 1~3 个专案挣利润和名声；没进案组的人接零散咨询和小额纠纷养团队。
  零散活有案源上限，随知名度、声望、场地成长——撞到顶就会提示「案源已满」，
  再招人也不涨钱，得先把名气做起来
- 收费贴着真实区间走：小案 6~10 万、大案 38~54 万、IPO 辅导 255~360 万、常年顾问 6~9 万/年
- **开庭排期**：未来六个月选窗口，11–12 月结案潮媒体关注高但判决保守，3 月和 9 月最宽松；定完可以改一次期，赔付已投入成本的 8%；开庭前只给评级区间和把握度，真结果等宣判
- **执业红线 0–100**：伪造证据、不披露冲突、垫诉讼费、向客户拍胸脯都会往上加，每两个月自己降 4 点。40 提示、65 被投诉、85 随时可能停业整顿、**100 吊销执照直接结束**
- **客户与复购**：结案评级高则关系涨，解锁后续委托（收费上浮 15–30%）；办好「常年法律顾问」会转成每月固定进账
- 五类客户资产、六家会抢案源抢排期抢人的竞争律所
- ★名律师四种专属特质：创收王 / 学术权威 / 媒体宠儿 / 万金油
- 20 条抉择事件（四阶段各 5 条）+ 3 条链式后果 + 12 条行业新闻
- 七阶经营目标、十项成就墙、律所编年史（可复制）
- **六种结局**：红圈所 / 精品所 / 外所下包工厂 / 被合并退场 / 还开着 / 吊销执照

游戏为纯静态单页应用，支持本机存档和手机浏览器游玩。

## 工程结构

```
index.html        UI 骨架与样式（全内联）
src/data.js       静态数据表（岗位/部门/案型/客户/场地/设施/对手/开局/排期/目标）
src/events.js     事件库（20 条抉择 + 3 条链式后果 + 12 条行业新闻）
src/art.js        美术资源清单与降级机制
src/game.js       逻辑与渲染
assets/scene/     场景图与氛围图（缺图时自动降级为纯 CSS）
assets/portrait/  人物立绘（缺图时自动降级为色块头像）
docs/规范-v1.md    分期施工规范
docs/出图清单.md    完整出图 prompt
tests/            核心逻辑测试（node tests/game-core.test.mjs）
```

技术底盘沿用《开个影视公司》：纯静态、无构建、无外部 CDN，GitHub Pages 直接跑，双击本地文件也能跑。
视觉是另起的一套，和影视版刻意拉开：

- 配色 **墨绿 + 黄铜 + 冷米白**（影视版是暖棕纸底 + 砖红 + 金）
- 按钮走公文风：2px 直角、1px 细描边、无底部硬阴影，主按钮实心墨绿带一道内铜边
- 结构件全部换掉：影棚双光束 → 百叶窗条形光影；2:3 电影海报 → 3:4 卷宗封套（带装订线和侧标签）；
  圆形徽标 → 方形铜牌；进度条 → 四段刻度，对应四个办案阶段；圆头像 → 方形圆角

## 美术资源

全部可选。`assets/` 里没有图，游戏照常运行；丢一张进去就多一处变好看，不需要改代码。

- **场景图 / 氛围图**：16 + 8 张全部入库，对照见 `docs/场景图对照.png`、
  `docs/场景图对照-第二批.png`、`docs/氛围图对照.png`
- **立绘**：15 张。其中 `bd-02` 是按律所规范新出的，另外 14 张还是从《开个影视公司》
  复用并按岗位重命名的（对照见 `docs/影视立绘对照.png`），可以慢慢换
- **头像缩略图**：`assets/portrait/s/` 下是 128×160 的小图，首屏的小头像用它
  （原图 512×640 塞进 32px 的头像框等于白下载 5 倍数据，首屏图片从 151KB 降到 50KB）。
  **换了立绘要重跑 `python3 tools/make-thumbs.py`**，忘了测试会报错
- 出图规范与完整 prompt 见 `docs/出图清单.md`；出完跑一遍测试，里面有 12 条针对
  文件名、编号、声明与文件是否对得上、尺寸、体积和缩略图的检查

## 测试

```bash
node tests/game-core.test.mjs      # 49 条核心逻辑断言
node tests/balance-sim.mjs 30      # 四种打法各跑 30 局完整十年，出经济曲线与分布
```

`game-core` 覆盖开局、260 周长跑、三种收费方案的回款方向、执业红线四档阈值与自然回落、
结案评级区间、存档 normalize 迁移、事件库自检（所有选项的 apply/onSkip 实跑一遍）、美术降级。

`balance-sim` 是数值审计工具，用稳健 / 激进 / 躺平 / 混合四种打法各跑若干局完整十年，
统计评级分布、红线峰值、各收费方案的实际收益和结局分布。改任何数值之后跑一遍，
分布见 `docs/规范-v1.md` 末尾的附录。
