# 《开个律所》出图清单 v1

给 GPT 用的完整 prompt，一张一块，复制整段即可。**文件名必须完全一致**（大小写、连字符），
丢进对应目录游戏就会自动用上，不需要改代码。缺图不影响运行，会自动降级成纯 CSS。

- 场景图 → `assets/scene/`，**1280×720，导出 WebP，质量 78，单张 ≤90KB**
- 氛围图 → `assets/scene/`，**960×540，WebP，质量 75，≤60KB**（会被拉伸裁切）
- 立绘 → `assets/portrait/`，**512×640，WebP，质量 80，≤70KB**
- GPT 出的是 PNG，转换命令：`cwebp -q 78 in.png -o out.webp`（没装就 `brew install webp`）。
  转不了也可以先把 PNG 直接改名成 `.webp` 丢进去应急（浏览器认内容不认后缀），只是体积大。
- 想给某个岗位加立绘：多出几张，文件名续编号（`litigator-03.webp`），然后告诉我，
  我把 `src/art.js` 里 `portraitCount` 的数字 +1。
